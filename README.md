# 🍽 French Classical Menu Challenge

A simple drag-and-drop learning game for Hospitality Studies students to practise the correct order of the 17 courses of the French Classical Menu.

Designed for TVET Hospitality students and published using GitHub Pages.

---

## 🌐 Live Website

https://elskeraal.github.io/french-menu-game/

---

## 🎯 Learning Outcome

Students arrange the 17 courses of the French Classical Menu into the correct order.

The game helps students learn both the French and English names of each course while practising the correct sequence.

---

## 📚 Based On

TVET FIRST

Module 4 – Menu Types

French Classical Menu

---

## ✅ Features

- Drag and Drop ordering
- Random shuffle every game
- Score out of 17
- Check Answers button
- Play Again button
- French and English names displayed together
- Mobile-friendly layout
- Desktop friendly
- Responsive design
- Works entirely in the browser
- No login required
- Free to use

## 🚀 Running Locally

1. Download or clone the project.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension.
4. Right-click **index.html**.
5. Select **Open with Live Server**.

The game will open in your browser.

---

## 🌍 Publishing with GitHub Pages

1. Create a GitHub repository called:

```
french-menu-game
```

2. Upload all files.

3. Go to:

```
Settings
→ Pages
```

4. Under **Source**, select:

```
Deploy from a branch
```

5. Choose:

```
Branch:
main

Folder:
/ (root)
```

6. Click **Save**.

Your website will be available at:

```
https://elskeraal.github.io/french-menu-game/
```
